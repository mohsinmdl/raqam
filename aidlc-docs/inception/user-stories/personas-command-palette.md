# Personas — Command Palette (Cycle 3)

Reuses the two established Raqam personas and adds one lens specific to this feature.

## Persona 1: The Existing Budgeter (reused)
Long-time Raqam user with many accounts, categories, and payees. Navigates constantly between Budget, Reflect, and specific accounts. Pain: the sidebar/account list gets long; finding one account or report is a hunt. **Wants**: jump anywhere in one or two keystrokes.

## Persona 2: The Fresh Starter (reused)
Newer user still learning where things live. **Wants**: type what they're thinking ("add expense", "categories", "net worth") and be taken there, without memorizing the app's structure. The palette doubles as a discovery surface.

## Persona 3: The Keyboard-First Power User (new lens)
Lives on the keyboard; already uses the app's `G`-then-key nav and `Shift+N` add-transaction. **Wants**: a single `⌘K` that reaches *everything* — pages, data, and actions — with full arrow-key/Enter/Esc operation and no mouse. Champions Recents for the handful of places they revisit.
